# Voting App

A Cloud and DevOps portfolio project by Enyeneobong.

## Project overview

This project will demonstrate how to build, containerise, deploy,
and operate a multi-container voting application on AWS.

## Project objectives

- Build an application with user registration and login.
- Allow one vote per user account.
- Process votes using a background worker.
- Display voting statistics in an admin dashboard.
- Store users and votes in PostgreSQL.
- Use Redis for queued work and cached results.
- Run the services with Docker Compose on AWS EC2.
- Automate testing, image builds, and deployment with GitHub Actions.
- Add health checks, application logs, and basic monitoring.

## Planned technology stack

- Flask: web application
- Node.js: background worker
- PostgreSQL: database
- Redis: queue and cache
- Docker and Docker Compose: containerisation
- AWS EC2: application hosting
- GitHub Actions: CI/CD
